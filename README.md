# Just IT Try

Веб-приложение для самостоятельного тестирования знаний по программированию.

🌐 **Демо:** [justittry.ru](https://justittry.ru/)

## 📋 Описание

Just IT Try — это платформа для проверки знаний по различным языкам программирования и технологиям. Приложение предлагает интерактивные тесты с подсветкой синтаксиса кода и детальной статистикой результатов.

## ✨ Основные возможности

- 🎯 **Тесты по языкам:** JavaScript, HTML, PHP, Dart, Python
- 📊 **Два уровня сложности:** Student (до 5 ошибок) и Developer (до 3 ошибок)
- ⏱️ **Ограничение по времени:** 20 минут на тест
- 🎲 **Случайные вопросы:**
- 💡 **AI-советы:** Получение рекомендаций по улучшению знаний
- 📱 **Адаптивный дизайн:** Работает на всех устройствах
- 🎨 **Подсветка синтаксиса:** Prism.js для читаемости кода
- 📤 **Шаринг результатов:** Поделиться в социальных сетях

## 🛠️ Стек

- **Frontend:** React 18, Redux
- **Подсветка кода:** Prism.js
- **Роутинг:** React Router
- **AI Integration:** OpenAI API
